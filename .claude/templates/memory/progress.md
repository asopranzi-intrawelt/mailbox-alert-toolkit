# Work-log

> Append-only, in ordine cronologico inverso (la voce più recente in alto). Ogni passo significativo di codice e ogni intervento manuale rilevante lascia una voce con data, file toccati, motivo e commit di riferimento. Qui confluisce anche il log di riconciliazione dei documenti `.docx`, con il nome del documento sorgente e l'esito, così la data di allineamento sopravvive a un clone. Ogni voce chiude con `**Template:**`, che vale `nessuna` oppure il numero della lezione registrata con `lezioni-template.py nuova`, secondo la regola `chat-non-e-memoria.md`.
